# MIRRA / 试穿间

## 方向

面向终端客户的轻量试穿工作室。暖白纸感底色、炭黑文字、柿橙操作色与低饱和绿灰预览区。用真实穿搭参考图、留白和清晰操作层次体现服装产品感。

## 设计规则

- 核心颜色：背景 #f7f6f2，面板 #fffefa，文字 #252724，次要文字 #72736d，操作色 #ea603b。
- 使用本机字体，不加载外部字体或图标；内联 SVG 统一线宽。
- 电脑：左侧工具栏，主视频区居左，上传/衣橱/偏好居右。
- 手机：上传和灵感选择最先出现；样例横向滑动，随后是视频、拍摄控件和试穿偏好。
- 320 / 375 / 390 / 768 / 1024 / 1440 与手机横屏布局验证。
- 不展示虚构的生成结果。未开摄像头时是明确的参考图拼贴；开摄像头后显示本地画面，有有效云端输出帧后切换 AI 结果。
- 上传入口始终在衣橱顶部，API Key 为页头入口，计费信息靠近主操作。
- 重要按钮有文字和图标；连接、录制、失败、存储结果有及时状态反馈。
- 原生 dialog 实现键盘焦点约束和 Escape 关闭；按钮可见焦点，支持减少动态效果。
- 拍照/录制默认导出到本地，并保存浏览器作品库。录制内容仅是画面，不包含页面操作层。

设计参考工作流：ui-ux-pro-max 的设计系统检索、无障碍和响应式建议；实现保持原项目的静态 HTML/CSS/JavaScript 技术栈。
