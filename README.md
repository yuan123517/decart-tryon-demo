# MIRRA 试穿间

面向电脑和手机的实时 AI 试穿工作室。由原 Decart 单页 Demo 升级而来，保留用户在前端输入自己的 API Key 的方式，运行时无需后端、构建工具或在线 CDN。

## 本地使用

在本目录启动静态服务器：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8765 。上传参考图，开启摄像头，输入自己的 Decart Key，再点击「开始 AI 试穿」。手机通过正式 HTTPS 静态站点访问；可将项目直接部署到 GitHub Pages、Cloudflare Pages 等静态托管服务。手机访问普通局域网 HTTP 地址时，浏览器通常不会开放摄像头。

## 功能

- 电脑端双栏工作室，手机端参考图置顶、衣橱横向滑动。
- 蜘蛛侠、一斤馄饨、牛仔、男士和两套女士参考图；支持图片上传、拖拽、网址导入与收藏。用户上传图在当前页面使用，刷新后重新上传；内置图与收藏偏好长期保留。
- 服装试穿 Lucy VTON 3.6、角色变身 Lucy 2.5、风格重绘 Lucy Restyle 2。前两者提供标准和极速模式，Restyle 使用标准速度。
- 提示词实时更新、智能提示词增强、摄像头切换、按前后摄分别记忆镜像、全屏、拖动式前后对比。
- PNG 拍照，0 / 3 / 5 秒倒计时；原始、9:16、1:1、16:9 画幅。
- Canvas 录屏，自动选择浏览器支持的 MP4 / WebM 编码，保留镜像及前后对比构图。录制仅包含画面，不录音，也不录入网页按钮；最长 10 分钟。
- 拍摄完成后默认启动本地文件下载，并存入当前浏览器的 IndexedDB 作品库；支持预览、再次下载、设备分享和确认删除。设置中可关闭自动下载。下载目录、保存提示和相册入口由浏览器与操作系统管理；手机可通过「分享」保存到文件或相册。
- Key 默认仅保存于本标签页的 sessionStorage；勾选「记住」后保存至 localStorage，可手动清除。源码不包含用户提供的 Key。
- 官方并发配额验证、本 Key 在本机的累计美元费用估算、首帧时间、输出帧率和 RTT。
- 连接取消后清理迟到连接；连接等待 45 秒超时；单次 1 / 3 / 5 / 10 分钟上限；可选闲置 60 秒和进入后台时自动停止；进入作品库也会自动结束 AI 会话。
- 键盘快捷键：S 拍照，R 录制 / 停止，空格开始 / 停止 AI 试穿。输入框和弹窗中不触发快捷键。

## 账户与计费

摄像头本地预览、拍照和录制本身不发起生成请求。AI 试穿直接连接 Decart，按官方规则计费。当前界面费率来自 2026-10-15 查阅的官方价格页：标准试穿 / 角色编辑 $0.02/s，极速 $0.04/s，Restyle $0.01/s。

优先使用服务器 `generationTick` / `generationEnded` 秒数估算消费；没有计费事件时，仅以开始收到输出画面后的时长估算。估算不是官方账单，也不是账户积分余额。累计值按 Key 的 SHA-256 摘要区分，真实账单请到官方控制台查看。

官方公开 API 当前没有账户积分余额接口。`GET /v1/realtime/quota` 返回的是并发会话数，不是 credits。详见 [官方能力核对记录](docs/decart-api-capabilities.md)。

视频与参考图片在开始 AI 试穿后直接交给 Decart 官方服务处理；用户 Key 只保存在浏览器中并用于官方接口。SDK 遥测在本产品中关闭。本机作品库按浏览器来源隔离，换设备、换域名或清理浏览器数据后不互通；请下载需要保留的作品。

## 验证

运行时不需要安装依赖。开发测试使用 Node.js、Playwright 和本机 Chrome：

```sh
npm install
npm test
```

测试前需启动上面的静态服务器。`BASE_URL` 可指定其他本地地址，`BROWSER_CHANNEL` 可指定浏览器 channel。

测试使用浏览器虚拟摄像头验证真实截图、录制、下载及 IndexedDB；生成服务通过模拟 SDK 验证连接生命周期、对比导出、计费事件及自动停止。未用用户的真实 Key 发起付费生成；真实 Key 仅对官方配额与文件列表做了查询。当前 32 项浏览器检查通过。桌面 Chrome 已验证 MP4 录制与回放；iOS / Android 真机与真实云端效果需部署后联调，录制容器依浏览器支持情况选择。

原始压缩包保持在原下载位置，可用于回滚。
